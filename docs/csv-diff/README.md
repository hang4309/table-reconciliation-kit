# 两个 CSV 找差异

直接双击 `index.html`，在浏览器中选择两份 UTF-8 CSV。左表和右表可以分别选择对应的精确键列，例如 `sku` 对 `商品编号`；再选择第 1 组需要逐字比较的列，例如 `qty` 对 `库存`。第 2–3 组比较列可按需添加。

先点“载入合成示例”可以看到：A 匹配、B 差异、C 只在左边、D 只在右边。真实文件中，空键和重复键不会被自动配对，而会标成“需人工处理”。每条结果都会保留左右两侧的原 CSV 行号和所选比较列值，便于回到原表核对；导出也保留这些信息。

工具只在浏览器本地读取文件。文件内容不上传，也不会改写原 CSV。离线下载包可断网使用。每份文件必须是有效 UTF-8，最多 5 MiB、10,000 条数据记录；字段行数与表头不一致、重复表头或不合法引号都会报错而不会改写内容。页面最多显示前 500 条，导出保留完整结果。规则或文件改变后旧结果会失效，必须重新运行。导出结果前，会为可能被电子表格当作公式的开头加单引号；仍请打开后抽查关键行。

它适合两份小型 UTF-8 CSV 的单键、最多 3 组对应列文本比较。它不处理 JSON、XLSX、多源数据、模糊匹配、数值容差、自动规范化或审计审批。
