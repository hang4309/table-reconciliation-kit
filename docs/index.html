两张表总量都是 35，
为什么仍对不上？

总量相同只能说明一个数字相同。逐条对照后，差异仍会藏在数量冲突、只出现在一张表的记录里。

逐条结果，而非只看总量

记录表 A表 B结果
A1010匹配
B2018数量冲突：差 2
C5缺失仅表 A
D缺失7仅表 B

总量相同，仍有两处需要处理

A：10 + 20 + 5 = 35⇄B：10 + 18 + 7 = 35

数量冲突记录 B 少了 2；表 A 独有的 C 为 5，表 B 独有的 D 为 7。两侧总量恰好相等，并不会让这些差异自动消失。
